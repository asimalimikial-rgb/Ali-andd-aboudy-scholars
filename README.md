# Ali & Aboudy Scholars — v1.3.0

تطبيق تعليمي شخصي لعلي (KG2) وعبودي (Grade 2)، بملفي تعلم منفصلين، مناهج متكاملة، ألعاب قصيرة، ومساعد صوتي عربي/إنجليزي يعمل محلياً.

## محتويات المشروع

- `index.html`: تطبيق الويب الأساسي، الدروس والمناهج والصور الأصلية المضمنة.
- `android/`: غلاف Android WebView وجسر Java/Kotlin لمحرك النطق المضمّن.
- `android/app/src/main/java/com/k2fsa/sherpa/onnx/Tts.kt`: واجهة sherpa-onnx TTS بإصدار 2.0.1.
- `android/app/src/main/java/com/alialiaboudyscholars/app/EmbeddedTtsEngine.java`: إعداد محرك Supertonic 3 وتوليد الكلام.
- `scripts/prepare-embedded-tts.sh`: تنزيل runtime والنموذج أثناء بناء APK فقط، مع التحقق من SHA-256.
- `.github/workflows/build-apk.yml`: فحوص JavaScript وبناء APK ونشر الإصدارات وفق إعدادات التوقيع الحالية.
- `MODEL-LICENSES.md`: تراخيص المحرك والنموذج وشروط إعادة التوزيع.

## بيئة التعلّم

- ثلاثة مداخل واضحة تجمع الدروس: English & Phonics، Mathematics، Science & Discovery.
- الحفاظ على كتب المنهج الأصلية والدروس ومعرّفاتها وتسلسل فتح الدروس.
- ملفات مستقلة لعلي KG2 وعبودي Grade 2.
- Jolly Phonics، Phonics Studio، Reading Adventure، Math Playground، Little Science Lab.
- Play & Learn، Daily Challenge، Smart Learning Coach، My Word Collector، الألعاب والإنجازات.
- Parent Dashboard، إعدادات الصوت، النسخ الاحتياطي والاستعادة.
- واجهة متجاوبة للهاتف واللوحي والكمبيوتر.

## سياسة الصوت — محرك مستقل مضمّن

1. يستخدم تطبيق Android محرك sherpa-onnx 2.0.1 مع نموذج Supertonic 3 متعدد اللغات لتوليد العربية والإنجليزية داخل التطبيق.
2. runtime والنموذج وملفات التشغيل مضمّنة في APK؛ لا توجد تنزيلات صوتية عند أول تشغيل أو أثناء استخدام الطفل.
3. لا يستخدم التطبيق `android.speech.tts.TextToSpeech`، ولا Web Speech API، ولا تطبيق TTS منفصل، ولا أي Network TTS API. عند تعطل المحرك يظهر خطأ واضح ولا يحدث fallback إلى محرك الهاتف أو الإنترنت.
4. يستخدم Android AudioTrack لتشغيل PCM الذي ولّده المحرك المضمّن فقط.
5. يستطيع ولي الأمر اختيار نمط صوت مستقل للإنجليزية والعربية، وضبط السرعة، واختبار الصوت وإيقافه.
6. تُنزّل ملفات runtime والنموذج في GitHub Actions أثناء بناء APK فقط. الروابط والإصدارات وبصمات SHA-256 مثبتة في `scripts/prepare-embedded-tts.sh`. لا تُضمّن ملفات النماذج الكبيرة في Git.
7. لا تُرسل أسماء الأطفال أو تقدمهم أو محتوى التعلم إلى أي مزود صوت خارجي. لا يتطلب مسار TTS اتصالاً بالإنترنت.
8. يجب على ولي الأمر قبول ترخيص نموذج Supertonic 3 من إعدادات الوالدين قبل استخدام الصوت؛ ملف الترخيص الكامل يُضمّن في APK.

## توقيت الشرح والتغذية الراجعة

- الشرح العربي المساعد يظهر ويُنطق قبل اختيار الإجابة فقط.
- بعد إرسال الإجابة لا يظهر ولا يُنطق شرح السؤال أو التلميح أو تعليمات الاختيار.
- الإجابة الصحيحة: تشجيع قصير مثل «أحسنت! إجابة صحيحة!».
- الإجابة الخاطئة: تشجيع قصير مثل «محاولة جميلة!» دون إعادة شرح السؤال تلقائياً.
- لا ينتقل التطبيق تلقائياً إلى السؤال التالي؛ الطفل يضغط متابعة بنفسه.

## بناء APK

يُبنى APK من مجلد `android/` عبر GitHub Actions. الإصدار المستقر الحالي v1.3.0 يستخدم `versionCode 9` و`versionName 1.3.0`. في Pull Requests يُبنى APK تجريبي منفصل بتوقيع Debug، أما الإصدار المستقر فيُوقّع بمفتاح Release المحفوظ في GitHub Secrets، وتتحقق workflow من بصمة شهادة التوقيع قبل النشر.

لا ترفع ملف JKS أو كلمة مروره إلى المستودع.

## الخصوصية والاختبار

- لا توجد إعلانات أو أدوات تتبع أو إرسال لبيانات تقدم الطفل.
- ملفات TTS لا تُطلب من الإنترنت أثناء تشغيل التطبيق.
- اختبارات CI والبناء تثبت سلامة المسار البرمجي والتغليف، لكنها لا تثبت وحدها جودة الصوت الفعلية على جهاز Android.
- لا يُعلن نجاح الصوت الحقيقي إلا بعد اختبار العربية والإنجليزية في وضع الطيران على جهاز Android، مع تغيير/تعطيل محرك TTS الافتراضي في النظام.
- GitHub Pages يستضيف واجهة الويب؛ التشغيل الصوتي المستقل الكامل متاح في APK الذي يضم runtime والنموذج.
