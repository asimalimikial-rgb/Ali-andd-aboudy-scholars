# Ali & Aboudy Scholars — v1.3.0

تطبيق تعليمي شخصي لعلي (KG2) وعبودي (Grade 2)، بملفي تعلم منفصلين، مناهج متكاملة، ألعاب قصيرة، ومساعد صوتي ثنائي اللغة.

## محتويات المشروع

- `index.html`: تطبيق الويب الأساسي، مع الدروس والمناهج والصور الأصلية المضمنة.
- `api/tts.js`: وسيط إلى FreeTTS Neural TTS المجاني.
- `tts-config.js`: عنوان خدمة الصوت لنسخة الويب.
- `android/`: غلاف Android WebView مع Android Native Text-to-Speech كحل أخير.
- `.github/workflows/build-apk.yml`: فحوص JavaScript وبناء APK موقّع ونشر GitHub Release.
- `tts-config.android.js`: عنوان خدمة الصوت الذي يُضمّن في APK.

## بيئة التعلّم

- ثلاثة مداخل واضحة تجمع الدروس: English & Phonics، Mathematics، Science & Discovery.
- الحفاظ على كتب المنهج الأصلية والدروس ومعرّفاتها وتسلسل فتح الدروس.
- ملفات مستقلة لعلي KG2 وعبودي Grade 2.
- Jolly Phonics، Phonics Studio، Reading Adventure، Math Playground، Little Science Lab.
- Play & Learn، Daily Challenge، Smart Learning Coach، My Word Collector، الألعاب والإنجازات.
- Parent Dashboard، إعدادات الصوت، النسخ الاحتياطي والاستعادة.
- واجهة متجاوبة للهاتف واللوحي والكمبيوتر.

## سياسة الصوت

1. السؤال يُنطق بالإنجليزية فقط قبل الإجابة. لا يظهر ولا يُنطق الشرح العربي قبل أن يختار الطفل إجابته ويتحقق منها.
2. بعد التحقق، تظهر تغذية راجعة وشرح عربي واحد، ويُقرأ الشرح بعد التغذية الراجعة.
3. المقاطع التي سبق توليدها تُشغّل من IndexedDB أولاً، فلا يُعاد طلبها ولا تستهلك حصة جديدة على الجهاز نفسه.
4. عند عدم وجود مقطع محفوظ، يستخدم التطبيق FreeTTS Neural TTS عبر وسيط Vercel، ثم يحفظ MP3 محلياً.
5. عند انقطاع الشبكة وعدم وجود مقطع محفوظ، يستخدم التطبيق Android Native TTS كخيار أخير.
6. حروف Phonics التي تحتاج IPA تبقى على مسار Android Native TTS المحلي؛ واجهة FreeTTS المجانية لا توثق دعم IPA/SSML phoneme.
7. تُمنع أسماء الطفلين من الإرسال إلى مزوّد الصوت؛ النصوص الشخصية تبقى على الجهاز.

## خدمة الصوت الشبكي المجانية

- لا يحتاج المسار الحالي إلى Azure Subscription أو بطاقة أو مفتاح API من المستخدم.
- الأصوات: en-GB-SoniaNeural للإنجليزية وar-EG-SalmaNeural للعربية، مع خيارات إضافية في إعدادات الوالد.
- توثيق FreeTTS المنشور يذكر للواجهة العامة 2,000 حرف يومياً و60,000 حرف شهرياً، وبحد أقصى 1,000 حرف للتوليد الواحد.
- حد FreeTTS المنشور 20 طلباً في الدقيقة لكل IP. وسيط Vercel يضع حداً احتياطياً 9 عمليات توليد في الدقيقة لكل نسخة دالة، تحسباً لكون كل توليد يتطلب طلب إنشاء وطلب تنزيل. هذا الحد الوقائي ليس ضماناً لحدود المزود عبر كل نسخ Vercel.
- ملفات الصوت المولّدة لدى FreeTTS متاحة لفترة محدودة؛ لذلك ينزّل الوسيط MP3 فوراً، ويحفظه التطبيق في IndexedDB حتى 80 MB تقريباً.
- الحصة والحدود المجانية قد تتغير، كما أن عنوان خروج Vercel قد يؤثر في احتساب الطلبات لدى المزود؛ يلزم اختبار الاستخدام الفعلي قبل اعتبار الخدمة مستقرة.
- GitHub Pages يستضيف واجهة الويب فقط؛ وسيط الصوت الشبكي يعمل على Vercel.
## بناء APK

يُبنى APK من مجلد `android/` عبر GitHub Actions. الإصدار v1.3.0 يستخدم `versionCode 9` و`versionName 1.3.0`. في Pull Requests يُبنى APK تجريبي بتوقيع Debug، أما إصدار `main` فيُوقّع بمفتاح Release المحفوظ في GitHub Secrets، وتتحقق workflow من بصمة شهادة التوقيع قبل النشر.

لا ترفع ملف JKS أو كلمة مروره إلى المستودع.

## الخصوصية والاختبار

- لا توجد إعلانات أو أدوات تتبع أو إرسال لبيانات تقدم الطفل.
- مفاتيح Azure تبقى على الخادم في Vercel.
- اختبارات CI تحاكي مزوّد الصوت؛ لا تثبت وحدها نجاح الاتصال الحقيقي أو جودة النطق.
- لا يُدّعى اختبار جهاز Android فعلي إلا بعد تجربته على الجهاز.
- GitHub Pages يستضيف واجهة الويب فقط؛ خدمة TTS تعمل من Vercel.
